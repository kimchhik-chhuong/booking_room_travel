# 🚀 Booking Travel - Development Setup Guide

## Quick Start (One-Click Solution)

### Windows Users
Simply double-click `start-dev.bat` to automatically:
- Detect your computer's IP address
- Configure Flutter environment
- Start Laravel API server
- Launch Flutter app

### Manual Setup (If needed)

#### 1. Laravel API Setup
```bash
cd booking_travel_api
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve --host=YOUR_IP --port=8000
```

#### 2. Flutter App Setup
```bash
cd booking_travel_flutter
flutter pub get
# The .env file will be auto-generated by the setup script
flutter run
```

## 🔧 How It Works

### Automatic IP Detection
The setup scripts automatically:
1. Detect your computer's local IP address (192.168.x.x or 10.x.x.x)
2. Create/update the Flutter `.env` file with the correct URLs
3. Start Laravel server with the detected IP
4. Launch Flutter app that connects automatically

### Environment Configuration
The system uses a `.env` file in the Flutter project:
```bash
# Auto-generated configuration
API_BASE_URL=http://192.168.1.105:8000
IMAGE_BASE_URL=http://192.168.1.105:8000
DEBUG_MODE=true
```

### Smart Image Loading
The `AppConfig` class automatically:
- Converts localhost URLs to work on mobile devices
- Handles both emulator and physical device scenarios
- Provides fallback images when loading fails
- Includes comprehensive debug logging

## 📱 Device Compatibility

### Android Emulator
- Uses `10.0.2.2:8000` for API access
- Automatically detected and configured

### iOS Simulator
- Uses your computer's IP address
- Requires network security configuration (already included)

### Physical Devices
- Uses your computer's local network IP
- Both devices must be on the same WiFi network

## 🛠️ Manual Configuration (If Needed)

If automatic detection doesn't work:

1. Find your IP address:
   ```bash
   # Windows
   ipconfig
   
   # Mac/Linux
   ifconfig
   ```

2. Update `.env` file manually:
   ```bash
   API_BASE_URL=http://YOUR_IP:8000
   IMAGE_BASE_URL=http://YOUR_IP:8000
   ```

3. Start Laravel with your IP:
   ```bash
   php artisan serve --host=YOUR_IP --port=8000
   ```

## 🔍 Troubleshooting

### Images Not Loading
1. Check console logs for image URL errors
2. Verify Laravel server is accessible at the configured IP
3. Ensure both devices are on the same network
4. Check network security configuration in Android manifest

### API Connection Issues
1. Verify Laravel server is running
2. Check firewall settings (allow port 8000)
3. Test API endpoint in browser: `http://YOUR_IP:8000/api/hotels`

### Network Security
The project includes network security configuration to allow:
- localhost connections
- Local network IP addresses (192.168.x.x, 10.x.x.x)
- HTTP traffic for development
